# Proxmox VE LogicModule suite — v2

Design work for the second generation of the Proxmox VE suite for LogicMonitor. It models a
cluster, its nodes and, optionally, its guests as separate resources, the way LogicMonitor monitors
vSphere. v1 lives in the sibling `Proxmox-LogicModule` repository.

- `docs/research/` — what LogicMonitor's own suites do, with sources
- `docs/superpowers/specs/` — the v2 design, for review before any plan or code

Nothing here is built yet.
